# インフラ構築タスク

## 目的

Embedded Infinispan アプリケーションを AWS ECS 上で複数タスク起動し、ALB 経由でラウンドロビンにアクセスできる環境を手動構築する。

## 成果物

- ECR リポジトリ
- ECS クラスター
- ECS タスク定義
- ECS サービス
- ALB、ターゲットグループ、リスナー
- S3 Ping 用 S3 バケット
- ECS タスクロール、タスク実行ロール
- CloudWatch Logs ロググループ
- デプロイ手順メモ

## タスク

### I1. AWS 基本設計

- [ ] 利用リージョンを決める。
- [ ] VPC、サブネット、セキュリティグループの利用方針を決める。
- [ ] ECS 起動タイプを決める。
- [ ] アプリケーションの公開ポートを決める。
- [ ] ALB をインターネット向けにするか、内部向けにするかを決める。

完了条件:

- ECS タスク、ALB、S3、CloudWatch Logs の接続関係が説明できる。

### I2. ECR 構築

- [ ] ECR リポジトリを作成する。
- [ ] ローカル Docker から ECR にログインする。
- [ ] アプリケーションイメージにタグを付ける。
- [ ] ECR にイメージを push する。
- [ ] ECS タスク定義から参照するイメージ URI を記録する。

完了条件:

- ECS から pull 可能なコンテナイメージが ECR に存在する。

### I3. S3 Ping 用 S3 バケット構築

- [ ] S3 Ping 専用バケットを作成する。
- [ ] クラスター識別用のプレフィックスを決める。
- [ ] ECS タスクロールに必要な S3 権限を付与する。
- [ ] 不要な外部公開を禁止する。
- [ ] ライフサイクルルールの要否を決める。

完了条件:

- ECS タスクから S3 Ping 用オブジェクトの読み書きができる権限になっている。

### I4. CloudWatch Logs 構築

- [ ] ECS タスク用ロググループを作成する。
- [ ] ログ保持期間を決める。
- [ ] タスク定義のログドライバーを `awslogs` に設定する。
- [ ] アプリケーションログが CloudWatch Logs に出ることを確認する。

完了条件:

- 操作ログを CloudWatch Logs Insights またはログストリームで確認できる。

### I5. ECS タスク定義作成

- [ ] CPU、メモリ、コンテナポートを決める。
- [ ] ECR イメージ URI を設定する。
- [ ] アプリケーション環境変数を設定する。
- [ ] S3 Ping 用のバケット名、リージョン、プレフィックスを設定する。
- [ ] キャッシュ名、`owners`、クラスタ名を設定する。
- [ ] ヘルスチェック設定を追加する。
- [ ] タスク実行ロールとタスクロールを設定する。

完了条件:

- ECS タスクを単体起動できるタスク定義が登録されている。

### I6. ALB 構築

- [ ] ALB を作成する。
- [ ] ターゲットグループを作成する。
- [ ] ターゲットグループのヘルスチェックパスを設定する。
- [ ] ALB リスナーを作成する。
- [ ] ALB セキュリティグループから ECS タスクのアプリケーションポートへ通信できるようにする。
- [ ] 試験端末から ALB にアクセスできるようにする。

完了条件:

- ALB DNS 名へアクセスすると、ECS タスク上の API に到達する。

### I7. ECS サービス作成

- [ ] ECS クラスターを作成する。
- [ ] ECS サービスを作成する。
- [ ] 希望タスク数を各キャッシュの `owners` より大きい数に設定する。
- [ ] ALB ターゲットグループに ECS タスクを登録する。
- [ ] Rolling update の設定を決める。
- [ ] サービス起動後、全タスクが healthy になることを確認する。

完了条件:

- 複数 ECS タスクが起動し、ALB ターゲットとして healthy になっている。

### I8. クラスター形成確認

- [ ] ECS タスクログで Infinispan クラスター参加ログを確認する。
- [ ] タスク数分のメンバーが同一クラスターに参加していることを確認する。
- [ ] ALB 経由の連続リクエストが複数タスクで処理されていることをログで確認する。

完了条件:

- S3 Ping によって ECS タスク間で Infinispan クラスターが形成されている。
- ALB のラウンドロビンにより複数タスクへアクセスが分散している。
